# Skipjack tuna biomass and ocean variability

This repository contains the analysis code used to examine how ocean conditions and climate variability affect simulated skipjack tuna (`Katsuwonus pelamis`) biomass across life stages in the western and central Pacific Ocean.

The workflow combines:

- SEAPODYM estimates of larval, juvenile, and adult skipjack biomass;
- oceanographic predictors derived from the SEAPODYM forcing fields;
- spatially varying generalized additive models (GAMs);
- complete ensemble empirical mode decomposition with adaptive noise (CEEMDAN); and
- diagnostics of variability associated with ENSO, the Interdecadal Pacific Oscillation (IPO), and long-term change.

The repository is an analysis archive for a research manuscript, not a packaged software library. Most source data and generated products are stored outside GitHub.

## Scientific workflow

The analysis asks three linked questions:

1. How well can oceanographic conditions reproduce absolute and anomalous skipjack biomass at the larval, juvenile, and adult stages?
2. Which environmental predictors matter most, and how do their effects vary geographically?
3. How do high-, medium-, and low-frequency environmental variability and long-term trends propagate into skipjack biomass?

Biomass is modelled with spatially varying GAMs. The R scripts use a signed log transformation,

\[
y^\ast = \operatorname{sign}(y)\log_{10}(|y|+1),
\]

so the same transformation can be applied to absolute biomass and anomalies. The GAMs combine global smooth terms with spatially varying tensor-product effects. Some analyses also test whether biomass from the preceding life stage improves prediction.

CEEMDAN is used to separate environmental and biomass variability into frequency bands before the climate-mode analyses.

## Required input data

The input data are not committed because of their size and, potentially, their distribution conditions. The workflow expects the following groups of files.

### Skipjack biomass

- `skipjack_biomass_by_age.nc`
- prepared seasonal tables:
  - `absolute_values_SEAPODYM_WCPO.txt`
  - `anomalous_values_SEAPODYM_WCPO.txt`

The two text tables are generated by `prepare_for_gam_skipjack_SEAPODYMforcing.Rmd`. That preparation script is referenced by the legacy README but is not currently present in this repository.

### Oceanographic forcings

The notebooks expect NetCDF fields whose names follow:

`forcings_netCDF/ipo_jra55np_1x30d_<variable>_1958_2022.nc`

Variables used across the workflow include:

| Group | Variables |
|---|---|
| Surface and productivity | `sst`, `mld`, `zeu`, `pp`, `pp75`, `uo`, `vo` |
| Temperature by layer | `T_L1`, `T_L2`, `T_L3` |
| Oxygen by layer | `O2_L1`, `O2_L2`, `O2_L3` |
| Zonal velocity by layer | `U_L1`, `U_L2`, `U_L3` |
| Meridional velocity by layer | `V_L1`, `V_L2`, `V_L3` |

### Climate indices

The climate-frequency analysis also reads:

- `ONI.txt` for ENSO;
- `derived_IPO.nc` for the IPO; and
- `CO2.txt` for the long-term atmospheric CO2 trajectory used in the analysis.

## Recommended execution order

1. Prepare the absolute and anomalous seasonal SEAPODYM tables with the external `prepare_for_gam_skipjack_SEAPODYMforcing.Rmd` script.
2. Run [`decomposition.ipynb`](decomposition.ipynb) to calculate CEEMDAN modes for the forcings and biomass fields.
3. Run [`prepare_IMFs_for_GAMs.ipynb`](prepare_IMFs_for_GAMs.ipynb) to aggregate the modes into frequency bands and create `forcings_minus_IMFs_seasons.csv`.
4. Run [`skipjack_GAMs_SEAPODYM.Rmd`](skipjack_GAMs_SEAPODYM.Rmd) to fit and save the GAMs.
5. Run [`skipjack_GAMs_SEAPODYM_skillassessment.Rmd`](skipjack_GAMs_SEAPODYM_skillassessment.Rmd) to calculate forecast skill.
6. Run one of the predictor-importance scripts. The `noL3` version supplies the reduced predictor set used by the current global/spatial plotting notebook.
7. Run [`skipjack_GAMs_SEAPODYM_IMFs_predictions.Rmd`](skipjack_GAMs_SEAPODYM_IMFs_predictions.Rmd) to generate frequency-specific biomass predictions.
8. If NetCDF output is required, run [`convert_csv_to_netCDF.ipynb`](convert_csv_to_netCDF.ipynb).
9. Run the three plotting notebooks to reproduce the global, spatial, climate-frequency, and El Niño diagnostics.

The CEEMDAN calculation is the most computationally expensive stage and was designed to run in parallel on NCI Gadi.

## Directory layout expected by the scripts

The code was developed on NCI Gadi and currently contains absolute paths rooted at:

`/g/data/es60/SEAPODYM/`

The main working directory is:

`/g/data/es60/SEAPODYM/pearse_GAMs/`

Within it, the scripts expect or create directories such as:

```text
pearse_GAMs/
├── EMD_forcings/
├── figures/
├── gams/
└── [intermediate CSV, TXT, and NetCDF files]
```

Before running elsewhere, replace the `setwd(...)` calls in the R Markdown files and the `wrkdir`/`os.chdir(...)` settings in the notebooks. Create the output directories before execution.

## Main outputs

The workflow produces four broad classes of results:

- fitted GAM objects (`.rds`) for each life stage and response type;
- model-skill statistics and manuscript tables;
- CSV and NetCDF fields containing global, spatial, and frequency-specific predictor effects; and
- publication figures showing predictor responses, spatial sensitivities, ENSO/IPO effects, and long-term changes.

The comments in the scripts and [`README.txt`](README.txt) retain provisional manuscript figure and table numbers. These labels may change as the manuscript is revised.

## Reproducibility notes

The current repository does not yet provide a one-command, end-to-end reproduction. Important constraints are:

- the source NetCDF data and climate-index files are external;
- the initial R data-preparation script is not committed;
- file paths are specific to NCI Gadi;
- generated products are not tracked in the repository;
- several filenames reflect earlier iterations of the workflow, so downstream inputs should be checked against the files actually written by the preceding script; and
- package versions are not pinned.

These points should be resolved before treating the repository as a fully portable replication archive.
